The plugin utility allows you to manage plugins installed and used by your project or tool. Here, you can import plugins from your system, or directly download plugins from the Infinite Garage.

### First look

The plugins utility has a menubar with an import modal, and optionally Infinite Garage buttons (if you allowed Vortex to go on the Web from the settings or from this window).

The sidebar gives you quick access to plugins by their topics/scopes, and the content bar lists all plugins installed in the project (and not the system!).

You can change the view mode with the settings button at the right of the menubar and search for specific plugins with the search bar at the top.

### Install new plugins

You can install a plugin from your system by clicking on the import window, you will see all the plugins of your system, simply click install to import them.

If you allowed Vortex to go on the Web, you will be able to download plugins from the Infinite Garage by clicking on the lightning icon after clicking on a similar lightning icon from the Infinite Garage page of a valid and compatible plugin.

### Delete a plugin

To delete a plugin from your project (and not the system!), simply click on the trash icon and confirm, you can reinstall it later.

### Start, restart or stop plugins

You can start a plugin by clicking on the green play arrow button.
You can restart a plugin that previously crashed by clicking on the orange arrows button.
You can stop a plugin by clicking the red pause button.
