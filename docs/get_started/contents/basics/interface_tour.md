## First look

This is Vortex Editor, your know into your project.

At the top, you can see the memubar. With mutiple menus to acces features quikcly. Under the menubar is the dockspace, in there every windows, editors and utilities you launch will dock there.

You can undock any docked little window into the void to create a new entire window. This allow you to have mutiple windows opening your main project. 

## Navigate on the Editor

On the menubar, the "Tools" menu, can open main tools such as the content browser or logs utility windows, but also somes installed modules utilities.
The "Project" menu gives access to the project settings, projects modules and plugins.
