Thanks to the Vortex Launcher, you can manage all of your projects and even import projects from others.

### Create a project
In the Vortex Launcher, go to the main section "Create a project", you can then select a template to build your project on top. (Modules installed in your system can provide templates for creating projects. Example: The eFusion module will give you templates to make firmwares and embedded systems, and MisterBin gives you templates for binary tools).

After selecting a template you can edit the name, some informations and the Vortex Editor compatible version.

Then you just need to hit the Create button, and your project is ready to be opened!

### Delete a project

To delete a project, select it in your project list and click on the Delete button, and confirm the deletion by writing the name of your project in the deletion modal and hitting Delete.

Warning: This action is irreversible and all the data of your project will be erased forever!

### Import a project
You can import an external project by clicking on import in the project selection page. After that, a little helper will show you your filesystem and will show you compatible projects to import.

Then select a project and simply click on "Import", after that, the project will be visible in your project list.

### Add more project pools
You can add new custom folders where your projects will be installed (if you want to use another disk or organize your projects in a certain way).

To do that, go to Settings of the Vortex Launcher (in the Options menu), and then go to the "System paths" section, search for "Project paths" and add the custom path you want before clicking on the green "+" button.

After that, while creating a project, you will be able to select which path to use for the project installation.
