The module utility allows you to manage modules installed and used by your project or tool. Here, you can import modules from your system, or directly download modules from the Infinite Garage.

### First look

The Modules utility has a menubar with an import modal, and optionally Infinite Garage buttons (if you allowed Vortex to go on the Web from the settings or from this window).

The sidebar gives you quick access to modules by their topics/scopes, and the content bar lists all modules installed in the project (and not the system!).

You can change the view mode with the settings button at the right of the menubar and search for specific modules with the search bar at the top.

### Install new modules

You can install a module from your system by clicking on the import window, you will see all the modules of your system, simply click install to import them.

If you allowed Vortex to go on the Web, you will be able to download modules from the Infinite Garage by clicking on the lightning icon after clicking on a similar lightning icon from the Infinite Garage page of a valid and compatible module.

### Delete a module

To delete a module from your project (and not the system!), simply click on the trash icon and confirm, you can reinstall it later.

### Start, restart or stop modules

You can start a module by clicking on the green play arrow button.
You can restart a module that previously crashed by clicking on the orange arrows button.
You can stop a module by clicking the red pause button.
