### Understand Vortex

Before continue let's clarify a little bit what is the Vortex Editor, compared to the Vortex Launcher.

The Vortex creative platform includes several elements that allow you to create, share content, and explore new creative possibilities. Let’s go over the main components of the Vortex project.

The Vortex Launcher is the central software of the platform. It allows you to create and manage your projects, as well as install new versions of the editor.

The Vortex Editor is the software launched by the launcher that allows you to interact with your projects.

Inside a project, with the editor, all main and core features are provided by modules, and plugins can be added to customize the experience. Thoses modules and pluigins are stored in the project directly, this allows sharing your project with configurations easely and have multiple types of projects.

### Take Vortex in hands
#### Create a project

First things firsts, let's create a Project ! To achieve that, simply go on the Vortex Launcher, then in Create a project section. Select a base (you can have mutiple project bases depending on whats starting point you want). Put a name and click on "Create project".

This is it ! Your project is now available on "Open a project section".

#### Install versions of Vortex Editor

To open a project, you need a valid version of the Vortex Editor, to get the Vortex Editor, the Vortex Launcher allows you to download it into the Vortex menu on top.

#### Open a project

Now you have your project and your editor ready, let's open the project ! Go on Open a project, select the project you've created, and click on Open.

#### Take in hand the editor

Now the Editor openned your project ! Congrats ! Your finally in it.
